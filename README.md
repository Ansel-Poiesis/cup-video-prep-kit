# 杯具图生视频准备工具包

本地工具，用于照片留白检查、镜头正文整理和手动生成费用记录。

在 Releases 中下载 cup-video-prep-1.0.zip，完整解压后，用电脑桌面浏览器打开“00-打开工作台.html”。详细说明、练习照片及许可文件均包含在压缩包中。

本工具不生成视频，不包含生成平台账号或积分。照片只在本地预览，导出的 TXT 保存文字和费用，不保存照片；关闭或刷新前请保存需要的文字。

自写工具与指南采用 MIT 非独占许可，两张练习照片采用 CC0。请保留压缩包中的许可与来源通知。
